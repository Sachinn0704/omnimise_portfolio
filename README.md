# Sachin B — Backend & AI Engineering Portfolio

A backend- and AI-focused portfolio showcasing projects in Python, SQL, computer vision, machine learning, security, and web application development.

## Profile Focus

The portfolio emphasizes building reliable software systems that combine backend services, data processing, AI capabilities, and security-oriented workflows.

## Technical Areas

- **Languages:** Python, Java, C, JavaScript, SQL
- **Backend:** Flask, FastAPI, Django, Django REST Framework
- **Databases:** MySQL, SQLite, MongoDB
- **AI/ML:** Scikit-learn, TensorFlow, OpenCV, Pandas, NumPy, Matplotlib
- **Frontend:** HTML, CSS, JavaScript, React
- **Tools:** Git, GitHub, Jupyter, VS Code, Google Colab
- **Cloud:** AWS, GCP, Azure fundamentals

## Featured Projects

### Blockchain E-Voting with Face Recognition
A voter-verification prototype using computer vision and structured vote recording.

### Multimodal AI System
A Python application exploring text, image, and speech processing in one workflow.

### Phase Encoding & ECC Steganography
An image-steganography project combining phase encoding with error-correction techniques.

### Task Dependency Management System
A Django/REST backend that manages task dependencies, detects circular relationships, and updates task status based on dependency state.

### SQL Student Performance Analysis
SQL projects covering relational database design, joins, aggregation, ranking, and academic performance analysis.
